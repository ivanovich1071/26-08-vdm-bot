# 26-08-vdm-bot

Диалоговый бот-магазин для **vdm.ru** (ЭЛТИ-КУДИЦ) — оборудование и комплекты
для детских садов и школ.

Каналы: **Telegram** и **виджет-консультант на сайт**; **MAX** — по готовности токена.
Модели: **Cloud.ru Foundation Models** (`deepseek-ai/DeepSeek-V4-Flash`).
Развёртывание: **Cloud.ru**.

## Что делает бот

- Консультирует по всему ассортименту на основе выгрузки 1С заказчика.
- **Подбирает по нормативным перечням**: понимает «2.20.63», «п. 2.1.14», «2.4»
  и словесные запросы вида «кабинет физики по приказу 838». Каждую рекомендацию
  сопровождает основанием, взятым из данных, а не придуманным.
- **Объясняет сами документы**: «что значит приказ 838», «на основании чего мы
  обязаны укомплектовать группу». Справка собрана из данных заказчика и работает
  даже при недоступной модели.
- Ведёт сделку как продажник: выявление потребностей → подбор → презентация →
  условия → фиксация следующего шага.
- **Держит контекст разговора**: помнит учреждение, кабинет, возраст детей, срок и
  бюджет и не переспрашивает то, что уже услышал.
- Ведёт корзину и доводит до сформированного заказа. **Онлайн-оплаты нет**:
  заказ уходит менеджеру.
- Соблюдает ФЗ-152: согласие до сбора контактов, маскирование персональных данных
  перед отправкой в модель, переписка хранится обезличенной не дольше 30 дней,
  экспорт и удаление данных по запросу.

## Быстрый старт

```bash
pip install -e ".[dev]"
cp .env.example .env

# собрать базу знаний из выгрузки 1С
python run.py ingest --source data/raw/<выгрузка>.xlsx

# реестр заказчика «пункт приказа 1057 → код 1С», затем пересборка
python run.py norms --source <реестр>.pdf
python run.py ingest --source data/raw/<выгрузка>.xlsx

# проверить поиск из консоли
python run.py search "мячи для спортивного зала в наличии до 2000 руб"

# виджет и демо-страница: http://localhost:8000/demo
python run.py widget

# Telegram-бот (нужен TELEGRAM_TOKEN)
python run.py telegram
```

Без ключа Cloud.ru бот работает: отвечает поиском по каталогу, корзина и заказ
полностью рабочие. Ключ включает диалоговый режим.

## Устройство

```
Telegram · виджет · MAX          адаптеры, без бизнес-логики
            ↓
       core/  ядро диалога       корзина · заказ · согласия · примитивы ответа
            ↓
agent · catalog · norms · orders · privacy
            ↓
  выгрузка 1С → products.jsonl → индекс
```

| Каталог | Что внутри |
|---|---|
| `src/ingest/` | Разбор выгрузки 1С и реестра приказа 1057, дерево каталога, очистка описаний |
| `src/norms/` | Приказы, пункты перечней, привязка товаров и справка по документам |
| `src/catalog/` | Поиск: точный по пункту перечня, лексический BM25, триграммы |
| `src/core/` | Диалог, корзина, заказ, хранилище, примитивы ответа |
| `src/agent/` | Клиенты моделей и переключение между ними, инструменты, проверка ответа, промпты |
| `src/orders/` | Приёмники заказа: Google Sheets, файл, заглушка CRM |
| `src/media/` | Фотографии товаров: разбор страниц, сдержанная загрузка, кэш, запись в базу знаний |
| `src/privacy/` | Маскирование ПДн, согласие |
| `src/adapters/` | Telegram, веб-виджет, MAX |
| `src/observability/` | Журнал диалогов — сырьё для доработки промптов |

## Статус

Работают: загрузка выгрузки, нормативный слой, поиск, корзина, оформление заказа,
Telegram-бот, виджет с демо-страницей, журнал диалогов, сбор фотографий,
нормативная справка, память диалога, ФЗ-152 в технической части. 202 теста.

Цены в ответе проверяются автоматически: сумма, которой не было в результатах
инструментов, в сообщение пользователя не попадает.

Карточка в базе знаний собирается целиком: код 1С, наименование, цена, остаток,
описание, состав комплекта, нормативное основание и фотографии. Формат — JSON,
по товару в строке; он же уходит в модель.

Ждём от заказчика: доступ к CRM, токен MAX, ключ Cloud.ru на его аккаунт.

## Чего нет в репозитории

Намеренно исключены материалы заказчика: выгрузка с ценами, PDF-каталоги,
сохранённые страницы сайта, полная версия плана и рабочий список вопросов.
Они содержат коммерческую информацию и передаются вне репозитория.
Здесь опубликована обезличенная версия плана.
