# 26-08-vdm-bot

Диалоговый бот-магазин для **vdm.ru** (ЭЛТИ-КУДИЦ) — оборудование и комплекты
для детских садов и школ.

Каналы: **MAX** (приоритетный) и **Telegram**.
Модели: **Cloud.ru Foundation Models** (`deepseek-ai/DeepSeek-V4-Flash`).
Развёртывание: **Cloud.ru**.

## Что делает бот

- Консультирует по всему ассортименту (8 486 позиций) на основе базы знаний.
- Ведёт сделку как продажник по CJM: выявление потребностей → подбор решения →
  презентация → условия и оплата → фиксация следующего шага.
- Показывает карточку товара как на сайте: фото, цена, наличие, кнопки количества.
- Ведёт корзину между каналами и доводит до оплаты, счёта или заявки менеджеру.
- Соблюдает ФЗ-152: согласия, маскирование ПДн перед отправкой в модель,
  экспорт и удаление данных по запросу.

## Чего нет в репозитории

Намеренно исключены материалы заказчика: прайс-лист с ценами, PDF-каталоги,
полная версия плана и рабочий список вопросов к заказчику. Они содержат
коммерческую информацию, хранятся отдельно и передаются вне репозитория.
Здесь опубликована обезличенная версия плана.
